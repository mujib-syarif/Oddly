# ODDLY
**Explore the past. Imagine the impossible.**

ODDLY combines two browser-based experiences:
- **Internet Time Machine** — discover archived versions of websites using the Internet Archive CDX API.
- **What If Machine** — explore interactive thought experiments with transparent assumptions and simple models.

## Run locally
`npm install`
`npm run dev`

## Build
`npm run build`

## GitHub Pages
The included GitHub Actions workflow builds and deploys the Vite app to GitHub Pages whenever changes reach `main`. In repository Settings → Pages, select **GitHub Actions** as the build and deployment source.

## Notes
- Internet Time Machine depends on the public Internet Archive service and the availability of archived captures. Some archived pages may be incomplete or block embedding.
- What If results are educational models, not predictions. The 100-billion-human scenario explicitly distinguishes arithmetic estimates from speculative societal consequences.
- No account, backend, or database is required. Preferences and recent activity stay in the browser.
